## 3. 產品概述

FHE AI NAS（with USB）是 AEGIS（`aegis.expert`）規劃中的地端私有知識庫 AI 節點：專利配方、製程參數、研究文獻等領域知識以靜態加密方式存放在組織自己的 NAS 上，由本地小型語言模型與 RAG 在地端完成推論，不依賴公有雲或外部閉源 LLM API。提問端以 USB 硬體金鑰派生的會話金鑰加密問題送入 NAS；模型產生的回答在離開地端隔離邊界前，必須由「回吐層」以同一把會話金鑰重新封裝成密文，才能回到提問端，並且只在 USB 在位時解密顯示。

v1 的交付基準是 S1「地端受控執行與雙向密文封裝」：傳輸、儲存與日誌層看不到明文答案，但推論運算本身在地端隔離環境內有受控的短暫解密點，因此**不是純密文域推論（S2）**。S2 只以特定固定 Kernel 的實驗模組形式研發，未通過測試前不標記 GA；在任意雲端大模型上做雙向密文互動（S3）則明確排除。

## 4. 核心特性與功能（可驗證者優先）

以下摘自 README，實作完成度均為 [待確認]。

1. **密文入鏈（REQ-BEH-01）**：Prompt 在客戶端封裝為密文；入口網關不接收明文 Prompt。
2. **密文回吐（REQ-BEH-02，核心增量）**：回吐層攔截模型輸出，以本次會話金鑰做流式或區塊密文封裝；未經回吐層加密的資料流由網路層強制斷流。
3. **USB 在位顯示與離線清除（REQ-BEH-03）**：USB 在位才解密顯示；拔除後覆寫顯示記憶體與 Session 變數（README 門檻 ≤ 200 ms [待確認]）。
4. **NAS 原文封鎖（REQ-BEH-04）**：正式服務模式下，檔案系統、向量資料庫與快取層不提供明文 Export 或無防護 Dump；禁止未授權者經 SMB/NFS/WebDAV 讀出明文。
5. **無權限金鑰阻斷（REQ-BEH-05）**：未授權金鑰查詢直接拒絕；輸出層不以有效金鑰重新加密。
6. **零原文日誌（REQ-BEH-06）**：日誌只記會話 UUID、時間戳、Token 計數、耗時與密文雜湊。
7. **領域 IP 授權（ACL Matrix）**：知識依命名空間切分，僅持有對應權限 USB 金鑰者可檢索。
8. **本地推論**：地端 SLM／LLM + 本地 RAG；README 舉例為 3B–8B 級別量化模型 [待確認] 實際支援清單。

## 6. 差異化定位

**同法人（AEGIS）相鄰產品**

- **vs. HEShell**：HEShell 是本機殼層與路由器，不擁有模型與知識庫，把 HE 密文送到具 L1/L2 能力的外部端點；FHE AI NAS 是**地端運算與知識庫節點**，自帶模型、RAG、儲存與回吐層。兩者分級體系不同（L0–L3 vs. S0–S3），不可交叉引用級別名稱。
- **vs. 斜槓123／斜槓104**：NAS 是**能力執行節點**（知識與模型留在這裡）；斜槓123／104 是**授權交易中樞**（管理誰能問、額度、收據），不收存明文知識包。平台不替代 NAS，NAS 本身也不提供市集與授權交易功能。

**跨法人**

- **vs. 寰境再製（OrbiLocale，AllView）**：OrbiLocale 規格書示例中的「FHE 私密 AI NAS」僅為示範資料；兩者無功能整合，也不應把 OrbiLocale 描述為本產品的行銷工具 [待確認] 如有實際合作再另行標註。
- **vs. AllView FHE Social、VeilProof 隱證**：AllView 的應用層產品；本產品為 AEGIS 地端基礎設施。
- **vs. Wonderland.center 三條線**：無功能重疊。

**相對於一般「私有化 AI NAS」**：差異在回吐層（答案離開地端前必須以同一會話金鑰重新封裝）、USB 在位解密與零原文日誌，以及對 S1／S2 邊界的明確揭露。

### 短文案（研發與製程知識）

配方、製程參數和研究文件是公司最不能外流的資料，卻也是最需要讓同仁快速查詢的資料。FHE AI NAS 把這些知識和模型留在你們自己的機房：問題以 USB 金鑰派生的會話金鑰加密送入，答案在離開設備前再以同一把金鑰封裝成密文，只有插著授權 USB 的人看得到。傳輸、儲存與日誌中都不留明文答案。

### 短文案（說清楚 v1 邊界）

我們把話說清楚：v1 是「地端受控執行」——模型在你們設備的隔離環境內推論，過程中有受控的短暫解密點，不是全程在密文上運算。全程密文推論目前只以特定運算的實驗模組研發，通過測試前不會標示為正式版。我們不提供雲端大模型的密文互動，也不保留任何改送雲端明文的後路。

### 賣點句

- 知識留在地端：本地模型 + 本地 RAG，不依賴公有雲 LLM。
- 去回都封裝：問題密文進、答案密文出，回吐層以同一會話金鑰封裝。
- 拔掉 USB 就看不到：USB 在位才解密，拔除即清除前端明文。
- 依命名空間授權：沒有對應金鑰，就不能檢索該領域知識。
- 日誌不留原文：只記 UUID、時間、Token 數、耗時與密文雜湊。
- 邊界寫明：S1 交付、S2 實驗、S3 排除。

| 運算實體 | 遠端公有雲或外部閉源 LLM API | 地端專屬硬體與本地 SLM/LLM |
| 儲存 | 僅轉發 | 大容量安全儲存 + 向量儲存，拒絕明文提取 |
| 回吐層 | 無 | 地端模型回吐層（Model Cipher Egress Layer） |

## 2. 安全等級 S0–S3（未達標前嚴禁跨級宣稱）

- **S0 輸入加密／回答明文**：前代套殼，嚴格廢棄；代碼出現明文回吐即 QA 阻斷。
- **S1 地端受控執行與雙向密文封裝（v1.0 交付基準）**：客戶端以 USB 派生之會話金鑰加密 Prompt → 地端隔離邊界（Isolated Local Runtime / Enclave / IPC 受控容器）內解封並本地推論與 RAG → 回吐層以同一會話金鑰重新封裝 → 密文輸出。傳輸、儲存、日誌層不可見明文答案。**推論熱路徑存在受控短暫解密點，不得對外宣稱為純 S2。**
- **S2 密文域同態推論（研發／實驗）**：模型計算直接於密文上執行（CKKS/TFHE），僅限特定固定 Kernel（機密評分、私密相似度比對、私密檢索 PIR）。研究現況引用：端到端 LLM 密文推論延遲仍以數十秒至數分鐘計（約 10^2–10^4 倍開銷；出處 [待確認]）。**未通過專屬效能與正確性測試前，不得標記 GA。**
- **S3 任意雲端大模型雙向密文互動**：明確排除於 v1；禁止預留雲端明文 API 回退路徑。

## 3. 架構與元件

    Client Tier：USB Hardware Key（Session Key Holder）＋ Client UI（USB 在位才解密）
          │ Encrypted Query / Encrypted Response
    AI NAS Appliance Node（Local）
      ├── Ingress API Gateway（TLS + Payload Verification）
      ├── S1 Local Controlled Enclave / Execution Pipeline
      │     ├── Storage Controller（AES-XTS at Rest，無明文讀出）
      │     ├── Local Engine（SLM / LLM + Local RAG）
      │     └── Local Cipher Egress（回吐層，K_session）
      └── Append-Only Audit Log（僅不透明雜湊，零明文）

- **儲存與推論載體**：NVMe/SATA 儲存池，ACL 與信封加密；地端 SLM（README 舉例 3B–8B 量化模型 [待確認]）或專用推論引擎。產品形態（自有設備或於 QTS/DSM/TrueNAS SCALE 容器部署）[待確認]。
- **USB 硬體金鑰載體**：非一般隨身碟，為會話金鑰載體（FIDO2/WebAuthn/Secure Element 或專屬 Token）；每次工作階段協商唯一會話金鑰；USB 拔除即抹除前端明文。
- **地端模型回吐層（核心增量）**：攔截模型輸出 → 以會話金鑰做流式或區塊封裝 → 封裝完成才可離開邊界；未經回吐層加密的資料流強制斷流。

## 4. 領域知識授權

- 專家／資料擁有者將知識注入 NAS（靜態加密），依知識命名空間配置 ACL。
- 持有合法 USB 金鑰之授權人員可提問並解密回吐密文；未授權者遭拒絕或僅取得無法解讀之密文。
- 設計目標：未授權者即使取得儲存媒體或側錄網路，也無法取得可讀答案（S1 推論熱路徑之可見範圍見威脅模型 [待確認]）。

## 5. 強制行為規範

- REQ-BEH-01 密文入鏈：入口網關不接收明文 Prompt。
- REQ-BEH-02 密文回吐：回傳 Payload 為純密文，以同一會話金鑰封裝。
- REQ-BEH-03 在位顯示與離線清除：USB 拔除後 ≤ 200 ms 覆寫顯示記憶體與 Session 變數（工程門檻）。
- REQ-BEH-04 NAS 原文封鎖：正式服務模式無明文 Export 或無防護 Dump。
- REQ-BEH-05 無權限金鑰阻斷：未授權金鑰直接拒絕；輸出層不以有效金鑰重新加密。
- REQ-BEH-06 零原文日誌：僅記會話 UUID、時間戳、Token 計數、耗時、密文雜湊。
